# MArcade - 2048

2048 Márcio's Arcade games

Based on the addictive 2048

## Screenshot

![2048](../Screenshots/2048.png)

## Running

To start game:

``` bash
./marcade.py 2048
```

## How to Play

Use your arrow keys to move the tiles. When two tiles with the same number touch, they merge into one!
